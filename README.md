# Şanlıurfa Kebap Website 🍢

Bu depo, Şanlıurfa kebap restoranı için hazırlanmış modern, sade ve kullanıcı dostu bir web sitesini barındırır. Amacı müşterilerin menüyü görmesini, iletişime geçmesini ve restoran hakkında bilgi almasını sağlamaktır.

---

## 📌 Özellikler

- Responsive (mobil uyumlu) tasarım
- Anasayfa, Menü, Hakkımızda ve İletişim sayfaları
- VEGAN / VEJETARYAN seçenekler
- Temiz ve okunabilir kod yapısı
- Kolay özelleştirme imkanı

---

## 🧱 Teknolojiler

Bu proje aşağıdaki teknolojilerle geliştirilmiştir:

| Teknoloji      | Kullanım Alanı                  |
|----------------|---------------------------------|
| HTML5          | Sayfa yapısı                   |
| CSS3           | Stil ve tasarım                |
| JavaScript     | Dinamik etkileşimler           |
| Bootstrap      | Responsive tasarım ve grid     |
| (Opsiyonel) .NET / C# | Backend (planlanan)     |

## 🚀 Kurulum

Adım adım yerel geliştirme ortamında çalıştırmak için:

1. Repo’yu klonla:
```bash
git clone https://github.com/eliftb/kebab-website.git
````

2. Klasöre gir:

```bash
cd kebab-website
```

3. Gerekli paketleri yükle:

```bash
# Eğer bir paket yöneticisi kullanıyorsan (Opsiyonel)
npm install
```

4. Projeyi çalıştır:

```bash
npm start
```
